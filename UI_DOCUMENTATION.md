## 📸 Screenshot Guidelines

### For Developers/Designers:
To capture these screenshots for documentation:

1. **Resolution**: Use 1920x1080 or higher
2. **Browser**: Chrome/Safari with dev tools closed
3. **Content**: Use realistic sample data
4. **Quality**: PNG format for crisp images
5. **Consistency**: Same browser, same zoom level (100%)

### Sample Data Recommendations:
- **User Names**: John Doe, Jane Smith, Alex Johnson
- **Messages**: Realistic conversation examples
- **Timestamps**: Recent dates and times
- **Files**: Common document types (PDF, images, etc.)
- **Status**: Mix of online/offline users
